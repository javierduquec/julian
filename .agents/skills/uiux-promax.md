# UI/UX Pro Max Intelligence Skill

## Description
Design intelligence database guidelines for generating optimized UI styles, color palettes, and production-ready React Native components.

## Rules
- **Component Safety:** Always verify SVG icons instead of raw emojis for visual elements in production layouts.
- **Micro-interactions:** Enforce immediate hover and active press feedback states on all custom buttons.
- **Accessibility:** Ensure high-contrast ratios between text and backgrounds, fully adapting to Dark Mode environments.
- **Design Systems:** Group color palettes by functional domains (SaaS, Fintech, E-commerce) utilizing semantic tokens (Primary, CTA, Background, Text).
- **Responsive Layouts:** Prioritize flexible flexbox constraints over absolute positioning to guarantee fluid cross-platform viewports.
